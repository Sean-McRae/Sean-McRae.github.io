About

What I do

I'm a Senior Principal Security Engineer with over a decade of experience in offensive security and vulnerability research. My work centers on application security assessments, building testing methodologies that scale, and finding the kind of bugs that don't show up in a default scanner run.

Lately that work has turned into tooling: taking what a strong manual report looks like and encoding it, so the gap between "found it" and "reported it well" gets smaller.
